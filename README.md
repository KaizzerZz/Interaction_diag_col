# Interaction Surface of RC columns
This repository consits of two main files or packages that can be used to perform the calculations needed to create an interaction surface for a RC column
## Sections
This package creates a Sections class which is defined with the geometric and material properties for the section. It has some methods related to it such as the compatibility of deformations for a certain angle and depth to the neutral axis.
## Columns
This package creates a Column class which helps automating to create a section with the characteristics of the most common used columns in buildings, it also performs the iterations and processes needed to build the interaction surface.
